# Drivy — template

Web app (PWA) per monitorare consumi, costi e manutenzione dell'auto. Material Design 3, installabile sul telefono. Dati salvati su Firebase Firestore.

Questa è la versione **template**: nessun dato personale, pronta da pubblicare con il tuo GitHub e il tuo Firebase.

## 👉 Come pubblicare la tua copia

Segui la guida passo-passo: **[ISTRUZIONI.md](ISTRUZIONI.md)** (~15 minuti, non serve saper programmare).

In breve:
1. Crea un progetto **Firebase** + Firestore e incolla la configurazione in `config.js`.
2. Crea un repository su **GitHub**, carica tutti i file e attiva **GitHub Pages**.
3. Apri l'indirizzo, aggiungi il tuo veicolo (o importa il tuo CSV di Drivvo).

## Funzioni
- Rifornimenti e manutenzione (con sotto-tipi: tagliando, gomme, bollo, assicurazione, ecc.)
- Consumo reale (metodo pieno-a-pieno, L/100km e km/L)
- Report con intervallo di tempo selezionabile (anche personalizzato)
- Più veicoli, con data e prezzo d'acquisto
- Importazione dello storico da un export CSV di Drivvo
